1、解析 HTML，生成 DOM 树
浏览器把标签结构转成对象树，只关心结构，不关心样式。

2、解析 CSS，生成 CSSOM 树
把所有样式（包括继承）计算好，形成样式树，只关心样式规则。


3、DOM + CSSOM 合成，生成 Render Tree（渲染树）
只保留需要显示的节点：
    不显示的（display: none）不会进渲染树
    visibility: hidden 会进，因为占位置

4、Layout（重排 / 回流）：计算每个元素的位置和大小
计算：位置，尺寸，盒模型，父子关系布局
只要 DOM 结构、尺寸、位置变了，就会触发 Layout。
比如：
offsetWidth / offsetHeight
clientWidth
修改 width、height、top、left
添加 / 删除 DOM 节点

5、Paint（重绘）：绘制颜色、背景、阴影等
绘制像素内容：颜色，背景，阴影，透明度，边框等
不改变布局，只改外观 → 只触发 Paint。

6、Composite（合成）：把图层合并，最终显示到屏幕
浏览器把页面分成多个图层，各自绘制后合并。
transform、opacity 只会触发合成，不触发 Layout 和 Paint，性能最高。


解决动画卡顿：

动画只用：transform + opacity
把动画元素提升为独立图层：will-change: transform
减少 box-shadow / filter / backdrop-filter
JS 计算丢进 requestIdleCallback 或 Web Worker
滚动 / 鼠标事件做节流防抖

赋值不会导致立刻重排，会等同步代码执行完成后重排
dom.style.left = '100px'; // 写

读取会导致重排，
第一次读取发现队列有未渲染的修改 → 强制重排1次，重排后，把所有布局信息全部缓存下来，第二次直接用缓存值，不重新计算
let a = dom.offsetLeft; // 读
let b = dom.clientWidth; // 读
let c = dom.getBoundingClientRect(); // 读
