```python

lis = [1, 2, 3]
dic = { name: 'hello', sex: 1 }

def fn(n):
    return n * 2

# 列表推导式
# [表达式(it) for it in 可迭代对象] fn(it)可以写成 it * 2，只要是个表达式就可以
res = [fn(it) for it in lis] # res 为列表

# 生成器推导式
# (表达式(it) for it in 集合)
res = (fn(it) for it in lis) # res 为生成器

# fn(it) for it in lis 不可以单独使用

# 集合推导式
res = { x for x in lis } # res 为集合set

# 字典推导式 {k:v}
res = { k:v for k,v in dic } # res 为字典dict
d = { i: i * 2 for i in [1,2,3] } # { 1:2, 2:4, 3:6 }
```
